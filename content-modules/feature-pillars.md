# ReviewMiner — Feature pillars

## Core engine
- Mine customer reviews for sentiment and themes
- Aspect coverage in one screen
- Honest limits when sample size is tiny

## Workflow & output
- Product and CX teams
- Paste reviews → themes → next actions
- Decision-support analysis only

## Trust & control
- No 100% accuracy claims
- No fabricated review quotes as facts
- Demo mode without a live API key
